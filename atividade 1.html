CSS

Css é uma linguagem declarativa auxiliar a documentos html para estilização de definição de comportamento. O css pode ser declarado de três formas distintas.

  1. Na tag style, definida no cabeçario do HTML
  2. Em um documento externo por meio da tag link
  3. InLine no proprio elemento HTML

CSS possui diversas formas de selecionar em quais elementos html uma regra será aplicada.

Seletores:
  • seletor por elemento
  • seletor universal;
  • Seletor por identificar único: li id="item" style #item
  • Class ou categoria
